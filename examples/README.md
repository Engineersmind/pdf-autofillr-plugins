# Examples

Usage examples for pdf-autofillr-plugins.

| File | Description |
|---|---|
| `basic_usage.py` | Load and use a built-in plugin |
| `custom_validator.py` | Write a custom phone number validator |
| `custom_extractor.py` | Write a custom invoice PDF extractor |
| `full_pipeline.py` | Full extract → map → validate pipeline |
| `plugin_discovery.py` | Auto-discover plugins from a directory |
